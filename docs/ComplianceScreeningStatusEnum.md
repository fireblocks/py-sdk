# ComplianceScreeningStatusEnum

A screening's lifecycle status.  - `PENDING` — accepted, not started - `RUNNING` — one or more steps in flight - `COMPLETED` — every step finished and the workflow outcome is set - `FAILED` — the screening could not be completed 

## Enum

* `PENDING` (value: `'PENDING'`)

* `RUNNING` (value: `'RUNNING'`)

* `COMPLETED` (value: `'COMPLETED'`)

* `FAILED` (value: `'FAILED'`)
