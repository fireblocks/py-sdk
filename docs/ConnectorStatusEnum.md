# ConnectorStatusEnum

The connector's own processing status for a step.  - `COMPLETED` — the provider answered - `BYPASSED` — no provider call was made; see `bypassReason` - `FAILED` — the provider call did not succeed - `FROZEN` — the step is held pending manual action 

## Enum

* `COMPLETED` (value: `'COMPLETED'`)

* `BYPASSED` (value: `'BYPASSED'`)

* `FAILED` (value: `'FAILED'`)

* `FROZEN` (value: `'FROZEN'`)
