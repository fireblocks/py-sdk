# QuorumRequestState

The approval request's overall state. Anything other than `PENDING` means the request is no longer awaiting approvals.

## Enum

* `PENDING` (value: `'PENDING'`)

* `APPROVED` (value: `'APPROVED'`)

* `REJECTED` (value: `'REJECTED'`)

* `CANCELLED` (value: `'CANCELLED'`)

* `TIMED_OUT` (value: `'TIMED_OUT'`)

* `FAILED` (value: `'FAILED'`)
