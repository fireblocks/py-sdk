# ScreeningOutcomeEnum

An `ACCEPT`/`REJECT` decision — the workflow's own outcome, a step's outcome, or the result of evaluating a step's outcome rules. `null` on a workflow outcome that is not decided yet.

## Enum

* `ACCEPT` (value: `'ACCEPT'`)

* `REJECT` (value: `'REJECT'`)
