# TransferDirectionEnum

A transfer's direction relative to the workspace. Set for `TRANSACTION_SCREENING` and `REGISTER_TRANSACTION`; it has no meaning for `ADDRESS_SCREENING`, which screens an address on its own.

## Enum

* `INBOUND` (value: `'INBOUND'`)

* `OUTBOUND` (value: `'OUTBOUND'`)
