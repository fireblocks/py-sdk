# UtxoSelectionConfigSourceEnum

Where the effective strategy was resolved from. `DEFAULT` means no stored row applies at this scope or any scope it inherits from - `effective.strategy` reports whichever strategy currently applies. `WORKSPACE` and `VAULT_ASSET` are stored rows.

## Enum

* `DEFAULT` (value: `'DEFAULT'`)

* `WORKSPACE` (value: `'WORKSPACE'`)

* `VAULT_ASSET` (value: `'VAULT_ASSET'`)
