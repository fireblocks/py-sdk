# UtxoSelectionStrategyEnum

UTXO selection strategy. `ADAPTIVE` is recommended: the engine chooses inputs at selection time. `ASC` spends smallest UTXOs first. `DESC` spends largest first.

## Enum

* `ASC` (value: `'ASC'`)

* `DESC` (value: `'DESC'`)

* `ADAPTIVE` (value: `'ADAPTIVE'`)
